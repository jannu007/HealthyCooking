# 🍃 からだ、ごはん。

身近な食材（スーパーで手に入るもの）だけで作れる、体に良い料理を紹介するWebアプリです。
それぞれのレシピを食べることで体にどんな影響があるのか（含まれる栄養素と期待される作用）もあわせて確認できます。

## 主な機能

- 手作りの厳選レシピ12品に加え、約48種類の身近な食材データベースと6種類の調理法テンプレート（味噌汁・炒め物・サラダ・煮物・スムージー・和え物）を組み合わせて自動生成した1,200品超のレシピを掲載（合計約1,250品）
- 自動生成したレシピの「体への影響」も、食材ごとに個別に調べた栄養素・効果データをそのまま組み合わせて構成しているため、内容の信頼性を保っています
- 「免疫力アップ」「疲労回復」「美肌」「腸活・便秘対策」「ダイエット・低カロリー」「血糖値対策」「目の健康」「骨・貧血対策」の8つの健康効果タグで絞り込み
- レシピ名・食材名でのキーワード検索
- レシピをクリックすると、材料・作り方・注目の栄養素・「食べると体にどんな影響があるの？」の詳細をモーダルで表示
- カラフルなブロブ（有機的な形）とアイコンで彩ったタイル一覧表示。検索・絞り込みバーは画面上部に固定表示（スティッキー）され、スクロールしなくても常に操作可能
- 大量のレシピでも迷わないよう、無限スクロールではなくページ番号つきのページネーション（24品/ページ）を採用。「ページ上部へ戻る」の floating ボタンも表示
- 自然（ネイチャー）をイメージした、浮遊する葉のアニメーションやスクロール連動の表示演出つきデザイン（`prefers-reduced-motion` 設定時は演出を自動的に控えめにします）
- 画像は、外部の画像ホスティングに依存すると大量のレシピで読み込み負荷や表示崩れのリスクがあるため、あえて自作のフラットな有機的イラスト（ブロブ＋絵文字）で構成し、常に軽快かつ確実に表示されるようにしています

## 使い方

ビルド不要の静的サイトです。リポジトリのルートで簡易サーバーを立てて `index.html` を開いてください。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 にアクセス
```

## 構成

```
index.html            # メインページ
css/style.css         # スタイル（ネイチャー×モーショングラフィックス）
js/data.js            # 健康効果タグ定義 + 手作りの厳選レシピ12品
js/ingredients.js      # 食材データベース（約48種、栄養素・健康効果つき）
js/dish-templates.js  # 調理法テンプレート + レシピ自動生成ロジック
js/app.js             # 一覧表示・フィルタ・検索・段階表示・モーダル表示のロジック
```
