# 🍃 からだ、ごはん。

身近な食材（スーパーで手に入るもの）だけで作れる、体に良い料理を紹介するWebアプリです。
それぞれのレシピを食べることで体にどんな影響があるのか（含まれる栄養素と期待される作用）もあわせて確認できます。

## 主な機能

- 12種類の健康レシピを紹介（材料・作り方つき）
- 「免疫力アップ」「疲労回復」「美肌」「腸活・便秘対策」「ダイエット・低カロリー」「血糖値対策」「目の健康」「骨・貧血対策」の8つの健康効果タグで絞り込み
- レシピ名・食材名でのキーワード検索
- レシピをクリックすると、材料・作り方・注目の栄養素・「食べると体にどんな影響があるの？」の詳細を表示

## 使い方

ビルド不要の静的サイトです。リポジトリのルートで簡易サーバーを立てて `index.html` を開いてください。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 にアクセス
```

## 構成

```
index.html       # メインページ
css/style.css    # スタイル
js/data.js       # レシピデータ（材料・作り方・栄養素・体への影響）
js/app.js        # 一覧表示・フィルタ・検索・モーダル表示のロジック
```

## 免責事項

掲載している健康効果に関する説明は、一般的な栄養学の知見を紹介するものであり、医学的な効能を保証するものではありません。持病や体調に不安がある方は医師にご相談ください。
